Antecedentes Penales

Asistencia para solicitar el certificado y realizar el seguimiento del trámite.

Qué necesitás

Ser mayor de 18 años, tener DNI argentino vigente y acceso al correo informado.

Cómo funciona

Revisás la información, iniciás la solicitud y completás únicamente los datos necesarios para la gestión. Cuando el servicio ofrece seguimiento, podés consultar su estado con el código correspondiente.

Iniciar gestión

TramiPago es un servicio privado de asistencia y gestión. No somos un organismo público. El precio del servicio se informa antes de iniciar.
